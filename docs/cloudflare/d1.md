# D1

Guest attendee records are stored in D1.

Fields:

- `name`
- `email`
- `rsvp` (`pending`, `yes`, `no`)
- `additionalGuests`
- `dietaryRequirements`
- `rsvpMessage`

## Create databases

Production:

```bash
wrangler d1 create wallabyfest-guests
```

Preview:

```bash
wrangler d1 create wallabyfest-guests-preview
```

## Run migration

Run against each environment database:

```bash
wrangler d1 execute wallabyfest-guests --remote --env production --file migrations/0001_create_guests.sql
wrangler d1 execute wallabyfest-guests-preview --remote --env preview --file migrations/0001_create_guests.sql
```

## API endpoints using D1

Self-service:

- `GET /api/private/guests/me`
- `PUT /api/private/guests/me`

Admin-only:

- `GET /api/private/guests`
- `POST /api/private/guests`
- `GET /api/private/guests/:id`
- `PUT /api/private/guests/:id`
- `DELETE /api/private/guests/:id`
