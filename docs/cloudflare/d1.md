# D1

Guest attendee records and game score data are stored in D1.

Guest fields:

- `guest_id`
- `name`
- `email`
- `rsvp` (`pending`, `yes`, `no`)
- `additional_guests`
- `dietary_requirements`
- `rsvp_message`
- `access_enabled`
- `invited_at`
- `last_synced_at`
- `sync_status` (`never`, `in_sync`, `pending`, `failed`, `drift`)
- `sync_error`
- `created_at`
- `updated_at`
- `updated_by`

Related tables:

- `game_runs`
- `game_scores`
- `game_high_scores` (view)

## Create databases

Production:

```bash
wrangler d1 create wallabyfest-guests
```

Preview:

```bash
wrangler d1 create wallabyfest-guests-preview
```

## Run migration

Run every SQL file in `migrations/` in filename order.

Production:

```bash
for file in $(ls migrations/*.sql | sort); do
	wrangler d1 execute wallabyfest-guests --remote --env production --file "$file"
done
```

Preview:

```bash
for file in $(ls migrations/*.sql | sort); do
	wrangler d1 execute wallabyfest-guests-preview --remote --env preview --file "$file"
done
```

## API endpoints using D1

Self-service:

- `GET /api/private/guests/me`
- `PUT /api/private/guests/me`

Admin-only:

- `GET /api/private/guests`
- `POST /api/private/guests`
- `GET /api/private/guests/:id`
- `PUT /api/private/guests/:id`
- `DELETE /api/private/guests/:id`
- `POST /api/private/guests/:id/access/enable`
- `POST /api/private/guests/:id/access/disable`
- `POST /api/private/guests/:id/send-invitation`
- `POST /api/private/guests/sync`
- `GET /api/private/guests/sync-status`

Game endpoints:

- `GET /api/game/high-scores`
- `GET /api/private/game/high-scores`
- `POST /api/private/game/runs/start`
- `POST /api/private/game/runs/:id/finish`

The admin-only `GET /api/private/guests/:id/last-seen` endpoint reads from KV, not D1.
