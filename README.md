# WALLABYFEST

A completely unneccessary website for my yearly birthday festival.

Most code generated by AI, not web content tho that's from the heart.

https://wallabyfest.co.uk

## Local Setup

```bash
npm install
npm run dev
```

Or to run the worker as well:

```bash
npm run dev:wrangler
```

Useful commands:

- `npm run lint`
- `npm run build`
- `npm run dev:wrangler`
- `npm test`

## Tests

Unit tests cover every module in `worker/` using [Vitest](https://vitest.dev/).

Run the full suite locally:

```bash
npm test
```

Test files live in `worker/tests/` and mirror the module they cover (for example, `worker/tests/auth.test.js` tests `worker/auth.js`).

Tests run automatically on every push and pull request via the CI workflow in `.github/workflows/test.yml`.
