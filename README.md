# WALLABYFEST

A completely unneccessary website for my yearly birthday festival.

## Terraform

Managing all the infra with terraform

### AWS

The `wallabyfest.co.uk` domain is managed in Route 53.

The terraform state is store in S3.

### Cloudflare

The rest of the stuff is deployed to Cloudflare.
